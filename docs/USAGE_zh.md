# CMA 报价助手 · 使用说明

厦门（CNXMN）起运的 CMA CGM SpotOn 实时运价抓取 + 报价单（合约）生成工具。

双击 **报价助手**（桌面图标，或文件夹里的 `报价助手.vbs`）打开界面，所有操作都在窗口里完成。
程序自带运行环境（Node / Python / Playwright），**不用装任何软件**。

---

## 一、首次使用

1. 双击 **报价助手**；
2. 弹出 CMA 登录页，用你的账号登录一次（之后会自动记住）；
3. 回到「报价」页签，点任意区域的 **开始** → 等 2~4 分钟，自动生成 Excel。

> 登录态约 25~30 分钟空闲就过期。程序里的「保持登录（保活）」默认每 5 分钟自动续一次；真掉线了在弹出的窗口重新登录即可，程序会自动继续。

## 二、三个页签

### 1. 报价

| 区域 | 目的港数 | 预计耗时 |
|---|---|---|
| 非洲 | 59 | 2~4 分钟 |
| 中南美 | 63 | 2~4 分钟 |
| 地中海 / 黑海 | 38 | 2~3 分钟 |

- **开始**：重新联网抓一遍并生成新表格；
- **全部更新（三个区域）**：一次跑完；
- 跑完在「报价表格」直接点 **打开**；右边小箭头（▾）可切换历史版本。

### 2. 免柜期查询

按国家 / 目的港查免柜期天数，可直接查看原始 PDF 页面。

### 3. 合约建立

在 SpotOn 上生成一张正式报价单（**不会**点「现在预订」，不会产生订舱）。

操作顺序：

1. 选**目的港**（下拉里标注该港口有几个船期）；
2. 填**每柜净重**（默认 25000 KGM）；
3. 选**柜型 / 柜量**，可组合（如 `1×20GP + 1×40HQ`，最多 3 种，默认 1×20GP）；
4. 选**船名 / 航次**（下拉里带该船期当天的 20GP / 40HQ 价格）；
5. 点 **开始建立报价**。

约 10 秒出报价号（`QSPOTxxxxxxxx`），自动写进「最近建立记录」。

**规则**

- 报价单 24 小时有效；
- 该航线已满舱时，程序会自动跳过，取下一条有舱位的；
- 不提交任何附加服务，所以**不会**带 Carbon Reduction（碳排放）费用；
- 勾上「自动续约」后，报价单满 **22 小时**（过期前 2 小时）会用**同样的船名 / 航次**自动再建一单；
- 续约失败（一般是价格变了）会在记录里显示 `失败：…`；
- 记录超过 24 小时自动清理。

### 4. 自动抢舱（同一页里的卡片）

用途：盯住**舱位已满、但价格便宜**的船期，一旦 CMA 放出舱位，立刻自动建报价单并通知你。

操作顺序：

1. 选**目的港**（只列有满舱船期的港口）；
2. 填**每柜净重**、选**柜型 / 柜量**；
3. 在**目标船期**里选一条满舱船期（默认 1 条，点 **＋** 可加到 5 条）；
4. 设**检查间隔**（5 ~ 60 分钟，默认 30）；
5. 点 **开始监控**。

**运行逻辑**

- 每个间隔周期查一次该港口的舱位；
- 目标船期仍满 → 记「仍满」，继续等；
- 检测到放舱 → **15 秒后二次确认** → 仍开就立刻建单，成功即停止监控；
- 连续 2 轮都查不到该船期 → 判定「已下架」，自动移出监控；
- 点「更新价格」时抢舱**自动暂停**，抓价结束自动恢复并立即补查一次；
- 登录失效 → 暂停并弹窗提示，登录后自动继续；
- 接口被限流（HTTP 429/440）→ 自动降到 60 分钟一次；
- 连续 5 轮检查失败 → 自动停止并弹窗；
- 勾了「程序重启后自动恢复监控」，重开程序会接着盯。

**通知**：界面顶部横幅 + 「抢舱记录」表格 + 桌面弹窗（不响铃）。

**规则**

- 抢舱只对**满舱**船期生效（可订的直接用上面的「建立合约」）；
- 抢到后自动停止，不会重复建单；
- 平均间隔越短抢到概率越高，5 分钟约每小时 12 次查询。

## 三、当前设置

| 项 | 说明 |
|---|---|
| 起运港（5 位代码） | 默认 `CNXMN`（厦门） |
| 最早开船日 | 默认 `3` 天后，早于该日期的船期不要 |
| 单柜最大净重 | 抓价时传给 CMA 的重量，默认 25000 KGM |
| 保持登录（保活） | 勾上后每 N 分钟自动 ping，防掉线 |

改完点 **保存设置**，下次运行生效。

## 四、生成的文件（`output/` 目录）

| 文件 | 内容 |
|---|---|
| `CMA报价_<区域>_<月日_时分>.xlsx` | **价格汇总**（分组/目的港/20GP/40HQ/重柜费/船名/航次/开船/航程/中转） + **价格变动图表** |
| `CMA价格明细_<区域>_<时间戳>.csv` | 每个船期的逐条明细（含舱位、船期、有效期） |
| `变化记录_<区域>_<时间戳>.xlsx` | 与上次比：涨价（红）/ 降价（绿）/ 换船（黄） |
| `合约记录.xlsx` | 已建立的报价单（含 20GP / 40HQ 价格、状态、自动续约） |
| `cache/` | 原始报价缓存，用于断点续跑 |

保留策略：报价 xlsx / 价格 csv / 明细 csv 各留最新 **3** 份；变化记录留 **5** 份；更旧的自动删除。

## 五、常见问题

**窗口打不开 / 一闪就没**
直接双击 `报价助手.vbs`。若报错，多是杀毒软件拦了 `runtime\node\node.exe`，把整个文件夹加入白名单。

**提示「需要重新登录」**
在弹窗登录即可，程序自动继续。空闲 25~30 分钟会过期，属正常。

**Excel 只读 / 出现重复文件**
关掉 WPS 的「启动时恢复上次打开的文档」；并删除 `output\` 下以 `~$` 开头的锁文件。

**某个港口没价格**
该港口当前没有可订船期，程序跳过并记入运行日志，属正常。

**换一台电脑能用吗**
能。整个文件夹拷过去即可（需 Windows + 已装 Chrome 或 Edge），**不用**装 Node / Python；首次使用重新登录一次 CMA。桌面图标可双击 `创建桌面快捷方式.bat` 重新生成。

## 六、目录结构

```
报价助手.vbs                  启动器（隐藏启动服务 + 打开窗口）
server.js                     本地服务（界面 + 接口）
ui.html                       界面
fetch.js                      抓价引擎（SpotOn 接口）
contract_api.js               合约建立（纯接口，10 秒出报价号）
contract_xlsx.py              合约记录 xlsx 生成
watch.js / watch_check.js     自动抢舱（定时查舱位 + 抢到即建单）
watch_xlsx.py                 抢舱记录 xlsx 生成
to_xlsx.py / month_chart.py   报价表格 / 价格变动图表
lib.js / login.js / lookup.js 浏览器控制、登录、港口解析
ports.csv                     港口表（区域 / 分组 / 查询名 / 代码 / 国家）
dd/                           免柜期库（索引 + PDF）
output/                       所有生成文件
runtime/                      内置 Node + Python
node_modules/                 Playwright 依赖
```

## 七、批量入口（不开界面也能用）

| 文件 | 作用 |
|---|---|
| `更新价格-非洲.bat` | 只更新非洲 |
| `更新价格-中南美.bat` | 只更新中南美 |
| `更新价格-地中海黑海.bat` | 只更新地中海 / 黑海 |
| `更新价格-全部.bat` | 三个区域全跑 |
| `0-直接出表-不联网.bat` | 用已有数据重新生成表格（不联网） |
| `创建桌面快捷方式.bat` | 按当前路径重新创建桌面图标 |
| `打包-生成便携版.bat` | 生成可拷到别的电脑的便携版 |
